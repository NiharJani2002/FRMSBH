EXTENSION #2 -- ReLU-Renew: Bias-Bounded Tracking for the Signed-Delta ReLU Model
------------------------------------------------------------------------------

Real data, Part A: a genuine market-breadth style signal -- for every ticker, every
trading day, +1 if today's volume rose vs yesterday, -1 if it fell (a real 'advance/
decline' style construction, tracked per-ticker and accumulated through a ReLU clamp,
the same v <- max(0, v+delta) rule that governs a message-queue depth counter).

  relative error (12 seeds) = 0.04944  [95% CI 0.03349, 0.06699]  (n=12 seeds)

Real data, Part B -- belief-decay under renewal (isolates the NEW ingredient):
A believer is handed a PERFECT initial read (best case for an attacker) on whether
one real ticker's oscillating ReLU value sits above its current sampling threshold,
then keeps re-using that stale belief while the oscillation continues.

CORRECTED THEORY (the previous version of this file said accuracy should decay
'toward chance,' meaning 0.5 -- that is wrong, and here is the fix). Once enough
renewals have happened, the CURRENT threshold is fresh and independent of the stale
belief, so accuracy converges not to 0.5 but to the STATIONARY probability that a
fresh Exp(1/tau) threshold agrees with that specific belief: for peak value v=51,
tau=50, that is mu_1 = 1-e^(-51/50) = 0.6394 if the belief was 'sampled', or mu_0 = 1-mu_1 = 0.3606 if the belief was 'not sampled'. This is exactly the
kind of Markov-chain convergence-to-stationary-distribution argument used to show DP
mechanisms under repeated refreshment stabilize exponentially fast (Chourasia, Ye,
Shokri, 'Differential Privacy Dynamics of Langevin Diffusion and Noisy Gradient
Descent,' NeurIPS 2021) -- same phenomenon, one discrete renewal step at a time
instead of one continuous diffusion step.

To test this cleanly, each of the two possible initial beliefs is forced explicitly
(rejection sampling over seeds until phase A lands on the target belief) and reported
SEPARATELY over 40 seeds each, tracking 'edge' = accuracy(t) minus the
belief's own theoretical stationary target. Edge should stay flat at q=0 (no decay
possible -- the threshold never changes) and decay toward 0 for q>0, regardless of
which belief was forced.

q=0 should hold edge flat (no possible decay -- the threshold never changes) at
whatever its starting value is; q>0 should visibly pull edge toward 0 as rounds
accumulate, in BOTH strata, confirming convergence to the belief's own stationary
target rather than to an arbitrary 0.5.

Paper comparison: this is the paper's own Section 5 open problem #2 (general ReLU
model, 'partial decrements may cause slight posterior biases to persist and
accumulate') -- left open there; ReLU-Renew is a first, explicitly partial, answer.
